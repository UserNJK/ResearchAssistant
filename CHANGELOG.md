# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2024-01-18

### Added
- Initial release of Research Assistant
- Web search agent using DuckDuckGo (free, no API key required)
- Paper reading agent with PDF parsing support
- Report writing agent with optional OpenAI integration
- LangGraph-based workflow orchestration
- Command-line interface with Rich output
- Configuration management with environment variables
- Support for research paper analysis from arXiv, Scholar, ResearchGate
- Markdown report generation
- Setup command for easy configuration

### Features
- Agentic AI workflow with multiple specialized agents
- Free to use without any API keys
- Optional OpenAI integration for enhanced reports
- Beautiful CLI with progress indicators
- Structured markdown reports with summaries and key findings
- Configurable search and analysis parameters
- Comprehensive documentation

### Supported Platforms
- Python 3.8+
- Cross-platform (Windows, macOS, Linux)
